# Trigger-TV

Westerns TV shows & movies 24/7.

Trigger TV uses the shared Infinity channel scaffold: synchronized playback, a viewer-local 7-day guide, a new deterministic lineup at 12:00 AM local time, channel remote, social sharing, StarCoin share progress, and live/start-over/rewind controls.

Programming is western-only and mixes full classic TV episodes with full-length western movies. Long compilation videos are segmented at real episode boundaries so each guide entry plays the actual episode instead of an arbitrary clip.

The remote first tries the shared Omni Control channel registry at `https://www-infinity4.github.io/Omni-Control/channels.json` and falls back to the built-in active-channel list if that registry is unavailable.

Live site: https://www-infinity4.github.io/Trigger-TV/
